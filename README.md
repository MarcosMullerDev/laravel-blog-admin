# Laravel Blog Admin

Sistema administrativo moderno desenvolvido em Laravel para gerenciamento de conteúdo.

---

## 🚀 Funcionalidades

- Autenticação de usuários
- CRUD completo de posts
- Upload de imagens
- Dashboard administrativo
- Busca de posts
- Paginação
- Status de publicação
- Agendamento de posts
- Interface moderna com TailwindCSS

---

## 🛠️ Tecnologias Utilizadas

- PHP 8
- Laravel
- MySQL
- TailwindCSS
- Vite
- Git/GitHub

## ⚙️ Instalação

```bash
git clone https://github.com/MarcosMullerDev/laravel-blog-admin.git

cd laravel-blog-admin

composer install

npm install

cp .env.example .env

php artisan key:generate

php artisan migrate

npm run dev

php artisan serve
```

## 👨‍💻 Objetivo do Projeto

Projeto desenvolvido para prática de arquitetura MVC, desenvolvimento de sistemas administrativos modernos e gerenciamento de conteúdo utilizando Laravel.
